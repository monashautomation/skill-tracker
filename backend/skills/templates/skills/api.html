Documentation

Base URL https://skills.monashautomation.com/api/v1/ (the same API is also at /api/). All bodies and responses are JSON.

Send your key as X-API-Key: <key> or Authorization: Bearer <key>. A missing, unknown or revoked key gets 401. Keys created with the Read scope may only make GET requests; any other method returns 403 {"error": "this key is read-only"}. Read + write keys can call every endpoint.

A key acts as a trusted service. Endpoints that act as a person (completing lessons, requesting inductions, admin-only changes) need X-Caller-Member: <discord id> to say who; that member's permissions apply. Anywhere a path says {member} you can use a Discord ID, directory ID or email.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/leaderboard/

People

GET/api/v1/people/scope: read

Everyone who isn't archived, with skills, inductions and ratings. Optional filters (combine freely): name (contains), email (exact), discordId, directoryId, position (contains), skill (skill name contains, level above 0), wantsToLearn (skill name contains), status. fields=id,name returns only those keys; an unknown field is a 400 listing the valid ones. archived=1 adds archived people (admin).

curl -H "X-API-Key: stk_your_key_here" \
  "https://skills.monashautomation.com/api/v1/people/?skill=cad&fields=id,name"
POST/api/v1/members/scope: write

Create or update a member by discord_id. Body: discord_id, email, display_name.

curl -X POST -H "X-API-Key: stk_your_key_here" -H "Content-Type: application/json" \
  -d '{"discord_id":"111","email":"jane@example.com","display_name":"Jane"}' \
  https://skills.monashautomation.com/api/v1/members/
GET/api/v1/members/{member}/scope: read

One member's profile: skills, lessons, inductions and points.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/members/111/
GET/api/v1/members/{member}/quiz-attempts/scope: read

Quiz attempt history. Needs X-Caller-Member: the member themself or an admin.

curl -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" \
  https://skills.monashautomation.com/api/v1/members/111/quiz-attempts/
POST/api/v1/members/{member}/points/scope: write

Award points. Body: points (positive), source (bounty, engagement, lesson, action_item, manual), description, optional external_ref (repeat calls with the same ref award once).

curl -X POST -H "X-API-Key: stk_your_key_here" -H "Content-Type: application/json" \
  -d '{"points":50,"source":"bounty","external_ref":"bounty:42"}' \
  https://skills.monashautomation.com/api/v1/members/111/points/
GET PUT/api/v1/members/{member}/skills/scope: read / write

GET returns the 6-axis ratings. PUT sets them (each 0 to 10: leadership, engineering, software, electronics, project_mgmt, communication). PUT needs X-Caller-Member of an editor.

curl -X PUT -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" -H "Content-Type: application/json" \
  -d '{"software":7,"engineering":5}' https://skills.monashautomation.com/api/v1/members/222/skills/
PUT/api/v1/members/{member}/skill-items/scope: write

Upsert skills: {"skills": [{"name", "category"?, "level"? 0-5, "wants_to_learn"?}]} (1 to 100). With X-Caller-Member, only that member's own profile or an editor may be changed.

curl -X PUT -H "X-API-Key: stk_your_key_here" -H "Content-Type: application/json" \
  -d '{"skills":[{"name":"CAD","level":3}]}' \
  https://skills.monashautomation.com/api/v1/members/111/skill-items/
DELETE/api/v1/members/{member}/skill-items/{skill_id}/scope: write

Remove one skill from a member.

curl -X DELETE -H "X-API-Key: stk_your_key_here" \
  https://skills.monashautomation.com/api/v1/members/111/skill-items/7/

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/skills/
GET/api/v1/leaderboard/scope: read

Top 25 by points.

Sync members from the People Directory now. Returns counts of created, updated, archived and restored.

curl -X POST -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/directory/sync/

Training

GET/api/v1/catalog/scope: read

Equipment groups and their published lessons.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/catalog/
GET/api/v1/lessons/{id}/scope: read

Lesson detail: markdown body and quiz info.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/lessons/1/
GET/api/v1/lessons/{id}/quiz/scope: read

Quiz questions. Correct answers are never sent.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/lessons/1/quiz/
POST/api/v1/lessons/{id}/quiz/attempt/scope: write

Grade a quiz on the server and record the attempt. Body: answers, one option index per question. Needs X-Caller-Member.

curl -X POST -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" -H "Content-Type: application/json" \
  -d '{"answers":[0,1,0]}' https://skills.monashautomation.com/api/v1/lessons/1/quiz/attempt/
POST/api/v1/lessons/{id}/complete/scope: write

Complete a lesson for the caller. Enforces the induction gate and quiz pass, then awards the lesson's points once. Needs X-Caller-Member.

curl -X POST -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" \
  https://skills.monashautomation.com/api/v1/lessons/1/complete/

Action items and roles

GET POST/api/v1/action-items/scope: read / write

GET lists meeting action items (?status=open or done). POST creates one: title, optional due_date (YYYY-MM-DD), member_discord_id. Needs X-Caller-Member.

curl -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" \
  "https://skills.monashautomation.com/api/v1/action-items/?status=open"
PATCH/api/v1/action-items/{id}/scope: write

Mark done with {"done": true}; awards its points once. Needs X-Caller-Member: the assignee or an admin.

curl -X PATCH -H "X-API-Key: stk_your_key_here" -H "X-Caller-Member: 111" -H "Content-Type: application/json" \
  -d '{"done":true}' https://skills.monashautomation.com/api/v1/action-items/3/
GET POST/api/v1/role-rules/scope: read / write

Points thresholds that map to Discord roles. POST (admin, via X-Caller-Member) adds one: discord_role_id, threshold_points, optional discord_role_name.

curl -H "X-API-Key: stk_your_key_here" https://skills.monashautomation.com/api/v1/role-rules/
